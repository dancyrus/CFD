## Acceptance gate — Redstone

Published: throat dia 15.5 in => A_t = 0.121736 m², mdot 355 lb/s = 161.03 kg/s, p0 = 318 psia = 2.1925 MPa, so delivered c* = p0·A_t/mdot = **1658 m/s**.

- computed ideal c* (frozen gamma): **1620 m/s** (-2.24%)
- computed ideal c* (CEA equilibrium): **1653 m/s** (-0.26%)
- tolerance ±8% — **PASS**

> **The gate passes, but from the wrong side.** Delivered c\* should be 92–96% of ideal; against these numbers it lands at 102% (frozen) / 100% (equilibrium), which no engine achieves. The chemistry is not the suspect — rocketcea and cantera agree to 0.1%, and the reactant cards reproduce CEA's own library propellants to 5e-6. The published trio is mutually optimistic instead: most likely 318 psia is INJECTOR-END pressure, which exceeds nozzle stagnation pressure by the Rayleigh loss across the combustor, so `p0·A_t/mdot` overstates delivered c\*. A 3–5% correction there restores a 96–99% efficiency and still clears this gate. Treat 1658 m/s as an upper bound on delivered c\*, not a measurement.
